The map editor

Open a map, pick things, move them, give them behaviours. If you know Unity's scene view you know this.

Open a map

  1. Mod ▸ Scenes in the project panel lists the maps your project touches. Double-click Crystal Shrine (t91_00).
  2. Any of the game's maps opens the same way from FF3 ▸ Maps - t01_01 is Ur. Changes to a game map go into a scene file of your project; the game's own file is never written.

Select and move

  1. Click the fox in the 3D view, or Fox in the hierarchy. The inspector shows it: Transform (position, rotation, scale), Model, Scene (tags, parent) and its Behaviours.
  2. Drag the arrows in the 3D view to move it (W tool); E switches to the rotate ring. Or type into Transform.
  3. Undo is Ctrl+Z, redo Ctrl+Y. The scene saves itself a moment after each change.

Add an object

  1. + add an object at the bottom of the hierarchy, or right-click in the hierarchy. A new object appears where the camera looks.
  2. Give it a model. In the inspector, Model ▸ Pick… opens the model picker: the game's characters, props and monsters as pictures, and your own glTF files first. Or drag a model from FF3 ▸ Models onto the 3D view.
  3. Tick "character" under the model if it should walk and be talked to (a villager); leave it off for a prop (a crate, a sign).

Give it a behaviour

Behaviours are what make an object do something. They attach like components in Unity.

  1. Add Behaviour in the inspector. A list drops down with a search box.
  2. Pick Talk and write a line or two under Lines. That is a villager.
  3. Pick Chest on a chest model (o001), choose the Item. That is a treasure chest, opened once, remembered in the save.
  4. Run in OpenFF and go and talk to it.

The built-in behaviours cover most of a map: Talk, Chest, Exit (a door to another map), Music, Sound, Wander and Roam (NPCs and props that walk about), Mesh (a glTF model, with collision), Trigger, WhenFlags, Cutscene. The reference lists every field.

Play here. The ▶ button above the 3D view starts the game on this map, at the selected object. The quickest loop there is: change, ▶, walk over, look.

Converting a game's map

On one of the game's own maps the hierarchy also lists its characters, logic and exits. You can move them and save the placement (a Steam mod), or convert a villager into an object of your mod's - the inspector offers it - which keeps the game's own dialogue and lets you add behaviours on top.
